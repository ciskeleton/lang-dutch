# 🇳🇱 CiSkeleton Language Pack — Dutch (Nederlands)

This repository contains the **Dutch (Nederlands) language pack** for [CiSkeleton (CSK)](https://github.com/ciskeleton).

CSK uses a modular translation system where each language is maintained as an independent package for easier updates and community contributions.

## 📦 Contents

* CiSkeleton language files for the **Dutch (Nederlands)** locale.
* CodeIgniter 3 language files under `language/dutch/ci3/`.
* CiSkeleton language files under `language/dutch/`.
* Admin translations under `language/dutch/admin/`.

## 🌍 Language

| Property      | Value                                                 |
| :------------ | :---------------------------------------------------: |
| Language      | Dutch (Nederlands)                                    |
| Locale        | `nl_NL`                                               |
| Tag           | `nl-NL`                                               |
| Flag          | 🇳🇱                                                    |
| Package       | `lang-dutch`                                          |
| Base language | [English](https://github.com/ciskeleton/lang-english) |

## 🤝 Contributing

Translations are welcome. Please keep the repository structure and language keys consistent with the [English language pack](https://github.com/ciskeleton/lang-english).

## 📖 About CiSkeleton

[CiSkeleton (CSK)](https://github.com/ciskeleton) is a modular platform foundation providing multilingual support, an admin panel, extensibility, and other application-level features.
